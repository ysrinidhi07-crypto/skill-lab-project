# skill-lab-project
problems : long queues, difficult in managing orders
solution:
Display the food menu.
Show food name and price.
Show whether an item is available.
Allow students to select food and quantity.
Calculate the total price automatically.
Allow students to place an order.
Generate an order number.
Show order status.
Provide a simple staff page to view orders.
Staff can change status to Preparing / Ready / Cancelled.
